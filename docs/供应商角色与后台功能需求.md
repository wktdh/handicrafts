# 供应商角色与后台功能需求

## 1. 业务模式

平台采用“统一运营、统一收款、供应商履约”的模式：

- 买家只接触平台品牌 Shouzuo Hub。
- 供应商不作为公开店铺或平台商户展示。
- 平台负责商品审核、海外定价、上架、客服、收款、售后和买家通知。
- 供应商负责提供商品资料、备货、发货和处理平台的内部协作请求。
- 当前所有供应商来自中国大陆，必要时由供应商发往平台集货仓，再由平台统一发往海外买家。

## 2. 账号角色

### 2.1 买家（buyer）

可浏览商品、下单、支付、查看订单、联系客服和申请售后。

### 2.2 供应商（supplier）

供应商是内部履约角色，不是公开卖家。供应商只能访问分配给自己的商品和订单。

### 2.3 平台运营（operator）

负责商品审核、价格、库存、供应商分配、订单履约、客服和售后。

### 2.4 平台管理员（admin）

负责账号审核、权限、风控、系统配置、财务和审计。

## 3. 供应商注册与审核

### 3.1 注册入口

- 注册页提供“买家”和“供应商”两种身份。
- 不再对外使用“店主/卖家入驻”作为供应商入口。
- 供应商注册后状态为 `pending_review`，不能立即接单。

### 3.2 供应商资料

- 联系人姓名
- 手机号、邮箱
- 公司/个人主体名称
- 身份或营业执照资料（按实际合规要求）
- 发货地址
- 可供货品类
- 备货周期
- 售后联系人
- 结算方式和备注

### 3.3 审核状态

```text
pending_review → approved → suspended
pending_review → rejected
```

- 审核通过后才能登录供应商后台。
- 停用后不能接收新订单，但应保留历史订单查看和售后协作权限。
- 审核、停用、恢复都写入平台审计日志。

## 4. 供应商权限边界

### 4.1 允许访问

- 自己提交的商品资料
- 平台退回修改的商品草稿
- 分配给自己的订单
- 自己订单的商品、数量、规格和履约地址
- 平台集货仓收货信息
- 发货确认、承运商和运单号
- 平台发来的内部协作消息
- 自己的履约统计和结算摘要

### 4.2 禁止访问

- 其他供应商的资料和订单
- 平台销售价、利润、优惠和支付流水
- 平台管理员后台
- 买家完整历史订单和无关个人信息
- 平台客服全量会话
- 退款审批、改价、发券、库存总控和系统配置
- 公开店铺名称、店铺主页、店铺链接

### 4.3 买家信息最小化

- 直发买家订单：显示该订单必要的收件人、地址、电话、国家/地区。
- 发往集货仓订单：不显示买家信息，只显示平台集货仓收货人、地址、电话和入仓单号。
- 所有买家信息访问写入审计日志，并支持脱敏显示和权限控制。

## 5. 供应商后台导航

供应商登录后只显示以下模块：

1. 工作台
2. 商品资料
3. 我的订单
4. 发货任务
5. 打印中心
6. 平台协作消息
7. 结算摘要
8. 账号设置

不显示平台运营、营销、财务管理、店铺装修、社区管理和系统设置入口。

## 6. 工作台

显示供应商最需要处理的事项：

- 待确认订单数量
- 待发货订单数量
- 已超时订单数量
- 待平台收货数量
- 异常订单数量
- 商品审核退回数量
- 平台协作消息数量
- 最近履约记录

每个指标都可点击进入对应列表。

## 7. 商品资料通道

### 7.1 供应商提交内容

- 商品标题
- 商品描述
- 商品图片和视频
- 材质、尺寸、重量
- 颜色、规格和 SKU
- 供货价（内部字段）
- 可供库存
- 制作周期
- 包装尺寸和重量
- 易碎、液体、磁性等运输属性
- 售后注意事项

### 7.2 平台审核流程

```text
供应商草稿 → 提交审核 → 平台审核 → 退回修改 / 审核通过 → 平台定价 → 上架
```

- 供应商不能直接发布到买家端。
- 平台销售价与供货价分开保存。
- 平台可以补充英文标题、英文描述、SEO、分类、运费和税费说明。
- 审核意见应返回供应商，并保留版本记录。

### 7.3 商品状态

```text
draft
submitted
needs_revision
approved
published
paused
rejected
archived
```

## 8. 订单派单与履约模式

### 8.1 平台派单原则

- 支付成功后由平台运营确认订单有效性。
- 平台按商品绑定的供应商生成履约任务。
- 同一订单只有一个供应商时，默认可直发买家。
- 同一订单包含多个供应商时，默认发往平台集货仓。
- 即使有多个商品，只要都由同一供应商履约，也可以直发。
- 平台运营可以手动覆盖默认履约模式。

### 8.2 履约模式字段

```text
direct_to_buyer              # 供应商直发买家
to_consolidation_warehouse   # 供应商发往平台集货仓
```

### 8.3 订单状态

```text
paid
pending_supplier_confirmation
supplier_confirmed
preparing
shipped_to_buyer
shipped_to_warehouse
warehouse_received
consolidating
international_shipped
delivered
exception
cancelled
```

### 8.4 供应商可执行操作

- 确认接单
- 申请无法供货
- 标记备货完成
- 标记已发货
- 填写承运商和运单号
- 上传装箱或发货凭证
- 报告缺货、破损、延迟等异常
- 查看平台运营的处理结果

供应商不能直接把订单标记为已签收、已完成或已退款。

## 9. 直发买家流程

适用：订单中的商品均由同一供应商履约，且平台运营允许直发。

```text
平台派单
→ 供应商确认接单
→ 后台显示买家必要收货信息
→ 供应商打印买家发货单/面单
→ 供应商发货并填写运单号
→ 平台同步买家物流状态
```

供应商可见字段：收件人、电话、地址、国家/地区、订单号、SKU、数量和规格。

## 10. 集货仓流程

适用：同一买家订单包含多个供应商商品，或平台运营指定集货。

```text
平台派单
→ 供应商确认接单
→ 后台只显示平台集货仓地址
→ 供应商打印平台入仓单
→ 供应商发往集货仓
→ 平台收货、验货、合包
→ 平台使用顺丰国际发往买家
```

平台集货仓信息需要提前在买家物流政策中公开说明，包括地址、处理时间、合包规则和异常处理方式。

## 11. 打印中心

### 11.1 平台入仓单

用于 `to_consolidation_warehouse`：

- 平台订单号
- 供应商任务号
- 入仓单号/条码或二维码
- 集货仓收件人、地址和电话
- 商品名称、SKU、数量和规格
- 预计到仓时间
- 备注：不得放入买家信息

### 11.2 买家发货单

用于 `direct_to_buyer`：

- 平台订单号
- 收件人、地址、电话、国家/地区
- 商品名称、SKU、数量和规格
- 平台售后提示
- 承运商和运单号留白或自动填充

### 11.3 批量打印

- 支持按日期、供应商任务和状态筛选。
- 支持批量生成 PDF。
- 已打印记录保存时间、操作者和打印版本。
- 打印内容变化后生成新版本，避免使用旧地址。

## 12. 发货和物流

- 发货前必须确认承运商和运单号。
- 同一供应商同一订单不得重复创建相同发货单。
- 运单号保存后进入物流跟踪。
- 直发订单由供应商提供第一段物流信息。
- 集货订单由供应商提供国内入仓物流，平台提供国际物流。
- 异常状态包括延迟、拒收、退回、丢件、破损和运单无效。
- 物流回调必须校验签名并支持幂等处理。

## 13. 供应商与平台内部消息

供应商只能看到与自己商品或订单有关的内部消息：

- 备货确认
- 缺货询问
- 规格确认
- 发货提醒
- 入仓异常
- 退货验收
- 售后举证

买家消息仍由平台运营账号统一接收和回复，供应商不能直接回复买家。

## 14. 售后与退货协作

- 买家非质量问题退货由平台承担并统一处理。
- 质量问题、错发、漏发和供应商原因的损失，平台可在内部向供应商追责或结算扣减。
- 买家退货统一寄回平台指定地址，不直接寄给供应商。
- 供应商需要配合提供批次、包装、质检和发货证据。
- 供应商不能批准退款或直接联系买家。
- 平台保存售后责任方、退货地址、运费承担方和结算调整记录。

## 15. 结算摘要

供应商可查看：

- 已完成供货订单
- 供货价金额
- 退货/扣款金额
- 待结算金额
- 已结算金额
- 结算周期和预计结算日

供应商不能查看平台销售价、平台服务费率和其他供应商结算数据。

## 18. 平台运营后台需要增加的功能

- 供应商申请审核
- 供应商启用、停用和资料查看
- 商品与供应商绑定
- 供货价维护
- 库存和备货周期维护
- 订单派单和重新分配
- 直发/集货模式选择
- 集货仓地址管理
- 供应商履约超时提醒

- 供应商操作审计

## 19. 安全与合规要求

- 供应商账号必须启用会话、CSRF 和登录限流保护。
- 买家地址只在确有履约需要时显示。
- 买家联系方式禁止出现在普通列表、导出文件和日志中。
- 打印文件设置短期有效链接或登录后下载。
- 供应商离职/停用后立即撤销会话。
- 所有敏感信息访问写审计日志。
- 平台统一说明集货仓、直发、预计时效、退货和退款规则。

## 20. 实施优先级

### 第一阶段：能履约

- supplier 角色和登录权限
- 供应商资料审核
- 订单派单
- 直发/集货模式
- 供应商确认接单和录入运单
- 入仓单和买家发货单打印
- 平台运营查看履约状态

### 第二阶段：可运营

- 供应商商品资料提交
- 商品审核退回
- 供应商内部消息
- 异常提醒和超时升级
- 集货仓收货、验货和合包记录
- 供应商履约统计

### 第三阶段：可结算

- 供货价和成本记录
- 退货责任归因
- 供应商结算摘要
- 扣款和对账
- 批量导出与审计报表

## 21. 验收标准

- 供应商登录后看不到平台运营菜单。
- 供应商只能看到分配给自己的订单。
- 单供应商订单可显示买家必要信息并打印直发单。
- 多供应商订单只显示集货仓信息并打印入仓单。
- 供应商确认接单、发货和录入运单后，平台订单状态正确更新。
- 供应商不能修改平台销售价或批准退款。
- 买家始终由平台账号统一接收和回复消息。
- 停用供应商不能接收新订单，但历史任务和售后记录可追溯。
- 买家敏感信息访问、打印和导出均有审计记录。
